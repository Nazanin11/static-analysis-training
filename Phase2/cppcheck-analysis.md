# Running Cppcheck

## Objective

Run Cppcheck on the BIRD v2.17.1 source code to identify potential bugs, coding issues, style problems, performance improvements, portability concerns, and other static analysis findings.

---

## Output Directory

A dedicated directory was created to store the generated report.

```bash
mkdir -p reports/cppcheck
```

---

# Running Cppcheck

Command:

```bash
cppcheck \
  --enable=all \
  --inconclusive \
  --force \
  --xml \
  --xml-version=2 \
  . 2> reports/cppcheck/cppcheck-result.xml
```

## Command Options

| Option | Description |
|---------|-------------|
| `--enable=all` | Enables all available checks, including warnings, style, performance, portability, information, and unused code analysis. |
| `--inconclusive` | Reports potential issues with lower confidence that may require manual verification. |
| `--force` | Forces analysis of all configurations and source files. |
| `--xml` | Generates the output in XML format. |
| `--xml-version=2` | Produces XML using version 2 of the Cppcheck output schema. |

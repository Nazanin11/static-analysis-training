# Normalize External Tool Results into SonarQube

## Objective

Convert the outputs generated by Semgrep, CodeQL, and Cppcheck into the SonarQube External Issues JSON format and import them into a single SonarQube project for unified analysis.

---

## Directory Structure

The following directories were created to store conversion scripts and generated reports.

```bash
mkdir -p scripts
mkdir -p reports/external
```

```
scripts/
├── semgrep_to_sonar.py
├── codeql_to_sonar.py
└── cppcheck_to_sonar.py

reports/
├── semgrep/
├── codeql/
├── cppcheck/
└── external/
```

---
# Step 1 – Convert Semgrep Results

## Automatic Ruleset

Command:

```bash
python3 scripts/semgrep_to_sonar.py \
reports/semgrep/semgrep-auto.sarif \
reports/external/semgrep-auto.json \
Semgrep
```

Console Output:

```text
Rules  : 1074
Issues : 9
Saved  : reports/external/semgrep-auto.json
```

---

## Security Audit Ruleset

Command:

```bash
python3 scripts/semgrep_to_sonar.py \
```

Console Output:

```text

Issues: 1770
Saved : reports/external/cppcheck.json
```

---

# Step 4 – Configure SonarQube

The generated external issue reports were referenced from the project configuration.

Example:

```properties
sonar.externalIssuesReportPaths=\
reports/external/codeql.json,\
reports/external/semgrep-security.json,\
reports/external/semgrep-auto.json,\
reports/external/cppcheck.json
```

---

# Step 5 – Run SonarScanner

Command:

```bash
sonar-scanner
```

Example scanner output:

```
Imported 283 issues in 76 files
Imported 44 issues in 26 files
Imported 9 issues in 4 files
```

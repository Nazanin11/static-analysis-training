# Running CodeQL

## Objective

Analyze the BIRD v2.17.1 source code using CodeQL by creating a CodeQL database and executing the default C/C++ security and quality query suite.

---

## Output Directory

A dedicated directory was created to store the analysis results.

```bash
mkdir -p reports/codeql
```

---

# Preparing the Project

Before creating the CodeQL database, the previous build artifacts were removed to ensure a clean build.

```bash
make clean
```

**Note:** Since the project was downloaded as a ZIP archive rather than cloned with Git, the following message appeared during the clean process:

```text
fatal: not a git repository (or any of the parent directories): .git
```
 This message is expected and does not affect the build or the analysis.

---

# Creating the CodeQL Database

Command:

```bash
codeql database create bird-db \
  --language=cpp \
  --source-root=. \
  --command="make -j$(nproc)"
```

## Result

The database was created successfully.

Database location:

```text
/home/nazanin/Projects/bird-2.17.1/bird-db
```

---

# Verifying the Query Packs

Command:

```bash
codeql resolve packs
```

The required C/C++ query pack was successfully detected.

```text
codeql/cpp-queries @1.7.0
```

---

# Running the Default Query Suite

Command:

```bash
codeql database analyze bird-db \
  codeql/cpp-queries:codeql-suites/cpp-security-and-quality.qls \
  --format=sarif-latest \
  --output=reports/codeql/codeql-results.sarif
```

## Result

The analysis completed successfully.

| Metric | Value |
|---------|------:|
| Query Suite | C/C++ Security and Quality |
| Queries Executed | 182 |
| C/C++ Files Analyzed | 172 / 211 |
| Output Format | SARIF |

Generated report:

```text
reports/codeql/codeql-results.sarif
```

# Running the Experimental Security Query Suite

To perform a more security-focused analysis, the experimental C/C++ security query suite was also executed.

A separate CodeQL database was created for this analysis:
```bash
codeql database create bird-db-experimental \
  --language=cpp \
  --source-root=. \
  --command="make -j$(nproc)"
```
The experimental security suite was then executed:
```bash
codeql database analyze bird-db-experimental \
  codeql/cpp-queries:codeql-suites/cpp-security-experimental.qls \
  --format=sarif-latest \
  --output=reports/codeql/codeql-security-experimental.sarif
```
The experimental suite contained:
```text
135 queries
```

# Comparing Default and Experimental Findings

The findings generated by the default and experimental analyses were compared using their:

* Rule ID
* Source file
* Starting line

The following command was used to extract and normalize the findings from the default analysis:
```bash
jq -r '
  [.runs[].results[] |
    [
      .ruleId,
      (.locations[0].physicalLocation.artifactLocation.uri // ""),
      (.locations[0].physicalLocation.region.startLine // 0)
    ] | @tsv
  ] | .[]
' reports/codeql/codeql-results-final.sarif |
sort -u > /tmp/codeql-before.txt
```
The same process was applied to the experimental analysis:
```bash
jq -r '
  [.runs[].results[] |
    [
      .ruleId,
      (.locations[0].physicalLocation.artifactLocation.uri // ""),
      (.locations[0].physicalLocation.region.startLine // 0)
    ] | @tsv
  ] | .[]
' reports/codeql/codeql-final.sarif |
sort -u > /tmp/codeql-experimental.txt
```
The comparison produced the following results:

Category	|Findings|
----------|--------|
Present in both analyses	|57|
Present only in experimental analysis	|16|
Present only in default analysis	|180|

Therefore, the experimental analysis did not simply reproduce the findings from the default suite. It detected a smaller, more security-focused set of findings.
